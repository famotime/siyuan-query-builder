# 易搭 siyuan-query-builder

## v0.9.5

### 新增

- **支持备注（Memo）查询与展示**：新增“备注”字段，统一整合块级备注与行内划线备注（`spans` 表 memo / textmark 备注），支持按备注进行条件过滤、排序以及在视图中展示。
- **新增“文本长度”字段**：新增“文本长度”（`textLength`）系统字段，映射底层 `blocks.length`，支持基于文本字数的数值过滤与排序。
- **新增“字数最多的块(Top10)”预置场景**：在日常管理分类下新增预置模板，一键按字数降序定位内容最长的块。
- **条件编辑器支持“小于”操作符**：在过滤条件中新增“小于”（`lt`）操作符，完善数值与日期字段的比较筛选能力。
- **排序规则支持“随机排序”**：视图排序规则新增“随机排序”选项（底层生成 `ORDER BY RANDOM()`），方便快速搭建随机漫游、抽样复习等场景。
- **支持清空查询历史**：侧边栏“最近运行”历史记录面板新增“清空历史记录”按钮，支持一键清空本地历史记录。

### 改进

- **引入 Lucide 图标库与 UI 质感提升**：集成 Lucide 线框图标，统一优化侧边栏、顶部栏和编辑器各操作按钮的视觉风格。
- **浅色主题（Light Theme）适配与优化**：全面优化浅色模式下的配色对比度与界面层次，提升日间模式下的视觉体验。
- **表单与控件细节修复**：修复下拉选择框（Select）箭头指示器显示异常，优化各设置面板的布局与交互细节。
- **优化嵌入块模板保存机制**：插入嵌入块时不再强制自动静默保存模板，改为由用户按需手动保存，避免产生冗余的模板快照。


## v0.9.0
为思源笔记用户设计的可视化查询构建器 — 无需懂 SQL，无需写代码，点几下就能把笔记整理成任务清单、项目看板或知识仪表盘。

### 🖱️ 可视化配置，零门槛自定义查询

通过高度易用的界面完成查询条件设置——选范围、定条件、加排序、分组，只需像搭积木一样点选，插件会自动在底层生成 SQL。你只需专注“我想看什么”，彻底告别代码焦虑。

### 📋 16 个预置场景，零门槛开箱即用

不想自己配置？没关系。插件内置涵盖日常管理、链接管理、自定义属性等分类的 **16 个常用查询场景**。用户可以直接参考或点击载入这些预设场景，一键运行获得结果，还能在此基础上零门槛微调，满足个性化需求。

### 📊 四种结果视图，按需自由切换

打破单一列表的枯燥展示，同一份查询结果，可以在以下四种视图间一键切换：

- **表格视图（Table）** ：最大化信息密度，适合结构化浏览、批量查阅任务详情。
- **看板视图（Kanban）** ：将任务或项目按属性（如状态、优先级）分组横向展示，进度追踪一目了然。
- **列表视图（List）** ：轻量线性浏览，聚焦内容本身，适合快速阅读。
- **统计卡片视图（Stats）** ：KPI 仪表盘式的聚合数据可视化，快速掌握宏观指标。

### 🔗 嵌入文档与模板复用，随处可用

- **保存查询模板**：将常用配置保存下来，下次直接复用，还能在同一模板下维护多个视图。
- **文档嵌入**：将查询结果以**嵌入块**形式插入任意文档，或在文档内按模板配置进行行内渲染，轻松打造你的“每日工作台”或“项目主页”。
