# siyuan-query-builder 开发计划

## 第一阶段目标

- 让用户无需手写 SQL 即可配置常见块查询
- 让查询结果以表格和看板消费，并可回写原始块属性
- 让查询模板可保存、复用，并可生成嵌入描述块

## 交付拆分

### 1. 工程底座

- 将模板插件重构为正式插件壳层
- 建立查询类型、查询编译器、运行时、模板存储
- 接入测试框架，优先覆盖纯逻辑模块

### 2. Query Builder MVP

- 范围选择：全部块、笔记本、文档、块类型、标签、属性键
- 条件编辑：等于、不等于、包含、为空、日期区间、最近/未来 N 天
- 排序与单字段分组
- 输出字段选择与自定义属性字段
- 常用预设模板

### 3. Multi View MVP

- 表格视图
- 看板视图
- 同一查询下的视图切换
- 点击结果跳转原始块

### 4. 数据写回与嵌入

- 状态、日期、优先级快速编辑
- 看板按状态拖拽回写
- 基于模板 ID 与视图类型生成嵌入描述块

### 5. 收口与验证

- 模板保存与加载验证
- 查询编译与运行时测试
- 构建、打包、基础元数据完善

## 当前实现结果

- 已完成第一阶段主体功能与逻辑测试基线
- 后续可继续扩展日历视图、时间线、真实嵌入渲染与更强字段映射
