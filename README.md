# 易搭——别让 SQL 成为你探索笔记的阻碍

## 楔子：沉睡的金矿

思源笔记的块级细粒度管理和底层 SQLite 数据库赋予了用户极高的自由度。我曾经兴致勃勃的给重要段落、关键任务和阅读笔记认真打上标签，甚至配置了详细的自定义属性，希望在未来某一天需要的时候，可以按场景或类别把它们找出来，随时汇集成册并批量处理。

然而，对于绝大多数普通用户而言，这些强大的底层能力往往变成了一座沉睡的金矿。当我想找出“本周未完成的高优先级任务”，“包含最多标签的文档”，或者“最近三十天已构建链接的活跃笔记”时，操作起来困难重重。我知道只要写一段 SQL 语句，这些散落的数据就能乖乖的排好队出现在我面前，可是需要了解数据库查询语法并熟悉思源笔记数据库结构才能写出 SQL——为了查一个简单的任务清单，还要问 AI 怎么写 SQL，这摩擦力有点太大了。

‍

## 易搭：零门槛的笔记数据查询工作台

带着这种不甘心，我开始构思一个能让普通用户也能轻松驾驭的解决方案。这也是“易搭 Query Builder”诞生的初衷——打破技术的重重门槛，为思源笔记这个开放底层数据库查询能力的笔记系统，提供一个可视化、可交互、可复用的数据查询工作台。

易搭提供零门槛的可视化查询配置，预置了 16 个开箱即用的预置场景：从日常管理的“今日编辑速览”、“往日笔记随机漫游”，到链接管理的“高反链核心笔记”、“双向连接核心区”，再到基于自定义属性的“任务清单”和“项目看板”。你只需在侧边栏找到最符合需求的一个，点击套用就能马上跑出结果。

你不再需要懂得什么是 SELECT，什么是 WHERE，你只需要关注查询场景是否匹配你的实际需要。而且“易搭”让你拥有自定义场景的自由，各种查询条件变成了一块块积木，你只需要更改查询范围、过滤条件、排序方式等组合条件，就可以获得更贴合需要的查询结果。

以下是一个标准操作流程：

1.  **选择预设场景（或从零开始）** ：打开插件面板，在侧边栏的“任务清单”、“项目看板”等预置场景中点击选择最符合你需求的一个。或者直接添加查询条件，各项条件支持“且”和“或”的组合逻辑。
2.  **微调查询与分组条件**：如果预设不完全符合要求，你可以直接在界面上增删过滤条件（如“状态 = 进行中”）、调整分组项（如按“标签”或“项目”分组）以及设定排序方式（如按“修改时间”倒序）。
3.  **确定展示形态**：根据数据的特点，在顶部一键切换“表格”、“看板”、“列表”或“统计卡片”视图，找到最适合的展示方式。
4.  **嵌入到指定文档**：选择目标文档，点击“生成嵌入块”，将这个动态视图插入到你的“个人主页”或“工作台”文档中。
5.  **浏览与处理结果**：在你的文档中直接浏览和处理查询结果。

## 核心价值与功能特性

### 可视化配置，零门槛自定义查询

通过高度易用的界面完成查询条件设置——选范围、定条件、加排序、分组，只需像搭积木一样点选，插件会自动在底层生成 SQL。你只需专注“我想看什么”，彻底告别代码焦虑。

不想自己配置？没关系。插件内置涵盖日常管理、链接管理、自定义属性等分类的常用查询场景。用户可以直接参考或点击载入这些预设场景，一键运行获得结果，还能在此基础上零门槛微调，满足个性化需求。

|分类|预置场景示例|
| ----------| ----------------------------------------------------------------|
|日常管理|最近 7 天更新文档、今日编辑速览、往日笔记随机漫游…|
|链接管理|高反链核心笔记、高正向引链笔记、双向连接核心区、无链接孤鸟笔记…|
|自定义属性|任务清单、项目看板、阅读清单、会议记录回顾…|

### 四种结果视图，按需自由切换

打破单一列表的枯燥展示，同一份查询结果，可以在以下四种视图间一键切换。在表格或看板视图中，你可以直接修改任务的状态、日期、优先级等属性，甚至拖拽看板卡片改变分组。所有的改动都会实时回写到对应的思源笔记原始块中，无需繁琐跳转。

- **表格视图（Table）** ：最大化信息密度，适合结构化浏览、批量查阅任务详情。

- **看板视图（Kanban）** ：将任务或项目按属性（如状态、优先级）分组横向展示，进度追踪一目了然。

  ![image](https://raw.githubusercontent.com/famotime/siyuan-query-builder/main/assets/image-20260730221145-sspp7gp.png)
- **列表视图（List）** ：轻量线性浏览，聚焦内容本身，适合快速阅读。

### 嵌入文档与模板复用，随处可用

- **保存查询模板**：将常用配置保存下来，下次直接复用，还能在同一模板下维护多个视图。
- **文档嵌入**：将查询结果以**嵌入块**形式插入任意文档，或在文档内按模板配置进行行内渲染，轻松打造你的“每日工作台”或“项目主页”。

### 与 Query & View 插件的对比

Query & View 是思源笔记生态中另一款优秀的数据查询和展示插件，相比起来，本插件更注重低门槛与开箱即用：

|对比维度|易搭 Query Builder|Query & View|
| ----------| --------------------------------------------| -------------------------------------------|
|**核心定位**|为普通用户设计的可视化构建器，主打低门槛|为开发者/极客设计的查询引擎，主打高自由度|
|**使用门槛**|零门槛，无需任何 SQL 或 JavaScript 知识|需要编写 JavaScript / SQL 代码|
|**上手方式**|可视化配置，提供 16 个开箱即用的预置场景|手写代码脚本，需查阅 API 文档|
|**结果视图**|内置并随时切换：表格、看板、列表、统计卡片|纯代码驱动的自定义 DataView|
|**属性回写**|支持直接在视图内编辑状态/日期/优先级并回写|通常作为只读面板展示结果|
|**嵌入文档**|支持嵌入块渲染|支持嵌入块渲染|
|**灵活度**|覆盖绝大多数日常和工作管理场景|几乎无上限，可实现任意自定义逻辑|
|**适合人群**|不懂代码的普通用户、效率工具爱好者|有编程能力的进阶用户、开发者|

如果你不想折腾代码、希望快速搭建可交互的个人工作台，易搭 Query Builder 是更低门槛、更直接的选择；如果你熟悉 JavaScript 和 SQL 并需要实现深度定制化查询逻辑，Query & View 无疑提供了更强大的自由度。两者各有侧重，可以互为补充。
